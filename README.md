# myutils

<ul>
  <li> Base64Util : Base64 轉換工具類，負責 Base64 的轉換工作</li>
  <li> BaseDataTransformer : 封裝了 ModelMapper 的工具類，負責物件的轉換工作</li>
  <li> BirtReportUtil : BIRT 的文件轉換類，負責產生文件，如: pdf、html</li>
  <li> ClassParseUtil : 物件轉換的工具類，負責將物件進行轉換特定樣式的資料，如: json、byte[] </li>
  <li> CustomerValidateUtil : 客製驗證專用的工具類，須搭配其他物件才能執行客製驗證 </li>
  <li>  DateTransformUtil : 日期轉換用的工具類，負責日期的轉換工作，如: String 轉 Date、Date 轉 String 等 </li>
  <li> DroolsUtil : 負責 Drool 流程引擎相關執行的工具類 </li>
  <li> ExcelMappingUtil : 負責將 Map 轉換為 Class 的工具類，通常用於 Excel 轉換後的 Map 資料 </li>
  <li> ExcelUtil : 負責將 Excel 資料轉換，如: 轉換為 Map<String, String>、Byte[]、InputStream 之類的 </li>
  <li> FtpUtil : 透過 FTP 方式進行 主機間 檔案傳輸的工具類 </li>
  <li> Html2PdfUtil : 封裝 Fly Sauce ，進行將 Html 轉換為 PDF 的工具類 </li>
  <li> InputStreamUtil : 提供 InputStream 與 常用格式 ( 如: byte[]、String、File、Base64 ) 之間的轉換 </li>
  <li> JasperReportUtil : 透過 Jasper Report 進行 PDF 產生的工具類</li>
  <li> JsonParseUtil : 將物件轉換為 json 工具類，與上方的 ClassParseUtil 類似 </li>
  <li> JxlsUtil : 透過 Jxls 模板建立 Excel 的工具類 </li>
  <li> MockDataLoadUtil : 負責讀取 Mock Data 的工具類 </li>
  <li> PathProcessUtil : 負責建立 URL 名稱的工具類，如: /mytils/edit/main/README.md </li>
  <li> PdfBoxImageUtil : 封裝 PDFBOX 的工具類，負責 PDF 圖片抽取 </li>
  <li> PdfBoxUtil : 封裝 PDFBOX 的工具類， 負責 PDF 的處理 </li>
  <li> SftpUtil : 透過 SFTP 方式進行主機間檔案傳輸的工具類 </li>
  <li> TemplateHtmlUtil : 封裝 Thymleaf 的工具類，負責 Email 模板的轉換 </li>
  <li> ZipUtil : 負責 Zip 檔案的工具類 </li>
</ul>
