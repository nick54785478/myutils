# myutils

<ul>
  <li> Base64Util : Base64 轉換工具類，負責 Base64 的轉換工作</li>
  <li> BaseDataTransformer : 封裝了 ModelMapper 的工具類，負責物件的轉換工作</li>
  <li> BirtReportUtil : BIRT 的文件轉換類，負責產生文件，如: pdf、html</li>
  <li> ClassParseUtil : 物件轉換的工具類，負責將物件進行轉換特定樣式的資料，如: json、byte[] </li>
  <li> CustomerValidateUtil : 客製驗證專用的工具類，須搭配其他物件才能執行客製驗證 </li>
  <li>  DateTransformUtil : 日期轉換用的工具類，負責日期的轉換工作，如: String 轉 Date、Date 轉 String 等 </li>
  <li> DroolsUtil : 負責 Drool 流程引擎相關執行的工具類 </li>
  <li> ExcelMappingUtil : 負責將 Map 轉換為 Class 的工具類，通常用於 Excel 轉換後的 Map 資料 </li>
  <li> ExcelUtil : 負責將 Excel 資料轉換，如: 轉換為 Map<String, String>、Byte[]、InputStream 之類的 </li>
</ul>
